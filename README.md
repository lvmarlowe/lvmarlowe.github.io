# Oddstrology

Responsive front-end website that presents whimsical fictional zodiac profile through custom page layouts, interactive navigation, responsive images, and a mobile-friendly sign carousel.

---

## Tech Stack

- **Languages:** HTML, CSS, JavaScript
- **Libraries:** Swiper
- **Fonts:** Google Fonts
- **Hosting:** GitHub Pages
- **Design Concepts:** Semantic HTML, responsive layout, media queries, Flexbox, forms, image handling, and interactive UI components

---

## Core Features

- Multi-page responsive website with Home, About, Signs, and Contact pages
- Mobile-friendly navigation with hamburger menu behavior
- Zodiac sign carousel using Swiper
- Responsive hero images and page layouts
- Styled contact form with required fields, dropdown selection, and radio buttons
- Custom visual identity using playful typography, dark backgrounds, and whimsical character concepts
- Semantic HTML structure with organized CSS styling

---

## Project Design

Oddstrology was designed as a fictional astrology-themed website with a deliberately strange and playful tone. The site uses a dark, storybook-inspired visual style with bright accent colors, decorative fonts, and character-focused sign cards. The layout was built to practice responsive design across mobile, tablet, and desktop screen sizes while keeping the site visually consistent across multiple pages.

## Assignment Context

This project was originally created for a web development course focused on building a website over multiple weekly assignments. The assignments introduced structural HTML, semantic HTML, CSS, media queries, Flexbox navigation, Google Fonts, responsive images, and form creation.

---

## Image Notice

The course requirements limited image use to original or AI-generated images. Stock images, royalty-free images, and other third-party image assets were not permitted for the assignment. I used AI-generated images created with Midjourney to meet the visual requirements while keeping the artwork aligned with the fictional concept of the site. I am currently revising the project and replacing the AI-generated images with licensed stock images or original illustrations where appropriate. Any replacement images will be reviewed for licensing requirements, attribution expectations, and long-term portfolio use.

---

## Why I Made This

Oddstrology began as a way to make a basic class website feel more fun, memorable, and visually distinctive. I was inspired by the funny, weird tone of *Affirmators!* affirmation cards and wanted to apply that kind of playful approach to my project without overlapping in content or format. Rather than treating the signs as serious predictions or spiritual guidance, the site uses astrology as a familiar structure for humor and front-end development practice.
